# NutriTrack

App desktop de acompanhamento nutricional (Windows).

## Stack

- Electron + React + TypeScript + Vite
- SQLite via `sql.js` (sem compilação nativa)
- Dados locais em `D:\Projetos\AcompanhamentoNutricional\data`

## Instalação / caches (somente D:)

- Node: `D:\Node`
- npm cache: `D:\temp\npm-cache`
- Electron cache: `D:\temp\electron-cache`
- Dados do app: `.\data`

## Desenvolvimento

```bash
npm install
npm run dev
```

Isso sobe o Vite e abre a janela do Electron.
